# Code and Cultivate

**Code and Cultivate** is a farming management game that combines agriculture with programming logic. Players can automate their harvests, manage an in-game economy, and optimize their farm using a drag-and-drop instruction block system.

## Features

* **Visual Programming:** Direct your farmers using logic blocks (`While` loops, `If/Else` conditions). Read the grid (walls, plantable soil, harvestable crops) to automate your farming loops.
* **Resource Management:** Grow resources like Fruits, Vegetables, and Berries, each with their own growth cycle.
* **Dynamic Shop:** Sell harvests to earn currency. Purchase new Farmhands, unlock additional logic blocks, and buy backup resources.
* **Character Customization:** Customize your farmers using RGB sliders for different body parts.
* **Speedrun Mode:** A built-in, precise speedrun timer with pause support for competitive play.

## How to Play

1. Drag and drop instruction blocks from the left palette to build a sequence.
2. Assign your farmers to the code columns.
3. Watch your farmers execute the instructions on the grid in real-time.
4. Sell your crops and use the shop to expand your farm.

## Installation

No Unity installation is required to play the game.

1. Navigate to the [Releases](../../releases) tab on this repository.
2. Download the latest release: `Setup_CodeAndCultivate.exe`.
3. Run the installer and launch the game.

*(Note for developers: To explore the source code, clone this repository and open the project in Unity).*

## Controls

* **[ W, A, S, D ]:** Move the camera.
* **[ Left Click ]:** Drag and drop blocks, interact with UI and shop, or click on a farmer to follow them.
* **[ Esc ]:** Open the pause menu.
